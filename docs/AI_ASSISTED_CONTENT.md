# AI-assisted content

AI assistance does not replace provenance, rights review, authorship judgment, accessibility work,
or human quality control. A generated output is not automatically safe to publish simply because a
tool produced it.

## Public eligibility

AI-assisted code, text, image, audio, animation, or other content may enter this repository only
when:

- the tool/provider terms permit the intended use and redistribution;
- all uploaded or referenced inputs were authorized for that use;
- no private, personal, confidential, promotional-video-derived, third-party NFT/branded, or
  otherwise excluded input was used;
- the output has been reviewed for recognizable third-party characters, brands, signatures,
  watermarks, sensitive data, and close copying;
- a human contributor accepts responsibility for selection, editing, testing, and the proposed
  license;
- required provenance is stored with the asset or documentation;
- the final bytes are listed and hashed in the asset manifest where applicable.

If a source input or prompt cannot be documented without exposing private or restricted information,
the resulting creative asset is not eligible for the public content pack.

## Provenance record

Record, as applicable:

- repository path and purpose;
- generation date;
- tool/provider, model, and model version when available;
- human operator/reviewer;
- exact public input assets and their rights;
- prompt and relevant parameters, excluding credentials;
- number and nature of iterations;
- human edits and post-processing;
- final SHA-256;
- proposed SPDX license;
- rights and visual-review decision.

Do not include API keys, private URLs, account identifiers, unpublished product strategy, or private
source material in a public provenance record.

## Code assistance

AI-assisted code receives the same review as any other contribution:

- understand and test every accepted change;
- check for copied notices, unexpected dependencies, insecure patterns, and private imports;
- preserve attribution and upstream licenses;
- avoid claims that a model output proves correctness or originality.

The contributor submitting the code must have authority to license the submitted contribution under
the repository's path-specific terms.

## Creative assistance

For images, audio, and other expressive content, retain enough process evidence to evaluate inputs
and output. Prompt-only similarity requests to a living artist, game, film, NFT collection,
promotional video, or identifiable commercial style are not accepted as provenance.

Use original art direction and non-brand references. Human review must also cover gameplay
readability, localization, accessibility, compression, metadata removal, and web-delivery size.

## Disclosure

Documentation and manifest records should accurately say “AI-assisted” when a generation model
materially shaped the published content. Do not overstate a model's authorship, imply endorsement by
the provider, or claim a rights determination that was not performed.
